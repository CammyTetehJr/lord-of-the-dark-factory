# Lord of the Dark Factory

The confidence layer that lets a repo fix its own trivial bugs and ship them to production with no human approving the change.

Pipeline: pre-checks, black-box fixer, oracle and diff inspection, gated canary deploy, signed audit trail.
When a check does not clearly pass, the bug goes to a human.

Target repo: [dark-factory-target](https://github.com/CammyTetehJr/dark-factory-target)

Team: Lord of the Dark Factory (AI Hackathon with Nebius & NVIDIA)
